REPOSITORY CONTEXT
The current repository is a React/Vite frontend + Express/Node backend application using GBrain as a persistent knowledge store and Gemini API function calling. It synchronizes Google Gmail and Google Calendar data and supports grounded natural-language queries across those sources.

The repository currently documents:
- Tier 1 calendar agenda queries
- Tier 1 Gmail search/unread queries
- Tier 2 Gmail + Calendar cross-source correlation
- strict grounding / explicit no-match behavior
- a Linear-inspired high-density dashboard
- live connector controls
- store statistics
- quick starter queries
- GBrain storage inspection
- streaming tool execution indicators

KNOWN CURRENT STACK
- Frontend: React + Vite
- Backend: Node.js + Express
- Persistent knowledge store: GBrain
- AI: Gemini API / function calling
- Integrations: Google Gmail + Google Calendar
- Deployment configuration: Render
